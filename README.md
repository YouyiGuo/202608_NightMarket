# 作業 1：打造專屬角色聊天機器人

選擇方向：台灣夜市小吃達人

## 實作內容

修改課程範例的聊天機器人，建立 `ChatManager` 管理對話流程，並加入台灣夜市小吃達人的角色設定。機器人會用繁體中文回答，專門介紹台灣夜市美食、推薦攤位選擇方式、說明口味特色與點餐建議。

## 執行方式

```bash
npm install
npm start
```

輸入 `exit` 可結束對話。

## 測試結果

已完成 5 輪以上對話測試方向：

1. 詢問第一次逛士林夜市要吃什麼
2. 詢問蚵仔煎與大腸包小腸的特色
3. 追問前面提過的小吃是否適合外國朋友
4. 詢問台南夜市推薦品項
5. 詢問甜點與飲料搭配

測試重點：角色設定明確、可連續對話、能記住前面提過的夜市小吃內容。
